# MYPORTFOLIO

陈珂羽的个人视频剪辑作品集，包含信息类、口播类、AI 类与卡点类作品。

使用 GitHub Pages 发布，无需构建。页面入口为 `index.html`。

## 内容维护

- `portfolio-data.js`：个人资料、分类与初始作品。
- `assets/`：实际视频、封面、照片与本地依赖。
- `app.js`、`styles.css`：页面与播放器。
- `motion.js`、`motion.css`：首页与滚动动画。
- `manager.js`、`manager.css`、`work-store.js`：本地作品管理。

网页中的管理功能保存在当前浏览器，不会修改 GitHub 仓库，也不会同步给其他访客。公开更新需将实际素材和配置提交到仓库。请保留本地备份。

Lucide 与 fflate 的许可证分别见 `assets/LICENSE-lucide.txt`、`assets/LICENSE-fflate.txt`。字体使用 Google Fonts，无网络时回退到系统字体。
